# Support

## How to file issues and get help

This project uses [GitHub issues](https://github.com/microsoft/WinMIDL/issues/new/choose) to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates. For new topics, file your bug or feature request as a new issue.

For help and questions about using this project, please look at the [README](./README.md), the [documentation under `docs/`](./docs/), and our [Contributor's Guide](./CONTRIBUTING.md) if you want to work on WinMIDL.

To report a security vulnerability, please follow the process in [SECURITY.md](./SECURITY.md) — **do not** open a public GitHub issue.

## Microsoft Support Policy

Support for WinMIDL is limited to the resources listed above.
